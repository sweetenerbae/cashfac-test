# Cash Factories Test Task

Приложение показывает реальные новости и позволяет читать один и тот же материал в разных эмоциональных режимах: нейтрально, радостно, грустно и иронично.

## Что внутри

- `backend` - Go API с загрузкой новостей, сохранением в SQLite и рерайтом текста
- `frontend` - React/Vite клиент с лентой новостей и страницей сравнения оригинала и рерайта

## Источник новостей

Для загрузки реальных материалов используется The Guardian Open Platform.

## Как устроен рерайт

Текст переписывается через Z.ai `glm-5.2` только после выбора интонации на странице новости. Готовая версия сохраняется в SQLite и повторно используется, пока исходный материал не изменился.

Факты в рерайте не должны меняться:

- имена
- даты
- числа
- места
- организации
- цитаты
- порядок событий

Перед сохранением backend проверяет, что модель действительно переписала текст. Если выразительную версию подготовить не удалось, в интерфейсе показывается fallback. Автоматические повторные запросы к модели не выполняются.

Для каждого рерайта API возвращает источник результата, длительность, количество LLM-запросов и число запросов, сэкономленных благодаря кешу.

## Запуск

Backend:

```bash
cd backend
make run
```

Frontend:

```bash
cd frontend
npm run dev
```

После запуска:

- backend: `http://localhost:8080`
- swagger: `http://localhost:8080/docs`
- frontend: `http://localhost:5173`

## Переменные окружения

В корне репозитория используется `.env`.

Основные переменные:

- `GUARDIAN_API_KEY`
- `ZAI_API_KEY`
- `ZAI_MODEL`
- `SQLITE_PATH`
